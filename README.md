# BrickOffice

Um escritório em pixel art que mostra, em tempo real, o que as suas sessões de código estão fazendo.

Cada projeto vira uma sala. Cada sessão vira um personagem com nome, mesa e uma tarefa visível: quem está trabalhando, quem travou, quem está esperando você e quem já terminou.
